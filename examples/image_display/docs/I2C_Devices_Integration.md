# I2C 设备集成文档

本文档详细说明了ESP32-S3与I2C设备（8通道ADC扩展器和TPL0401A数字电位器）的集成过程、实现细节和测试结果。

## 1. 设备概述

### 1.1 硬件配置
- **I2C总线**：使用ESP32-S3的I2C扩展接口
  - SCL: GPIO_NUM_40
  - SDA: GPIO_NUM_41

### 1.2 连接的I2C设备
1. **ADC扩展器**
   - 地址：0x18
   - 功能：8通道模拟输入
   - 分辨率：8位（内部映射至12位）

2. **TPL0401A数字电位器**
   - 地址：0x40
   - 阻值范围：0Ω - 10kΩ
   - 分辨率：128步进

## 2. 实现细节

### 2.1 TPL0401A数字电位器

#### 2.1.1 阻值计算
```c
uint16_t tpl0401a_value_to_resistance(uint8_t value) {
    // 0-127范围映射到0-10kΩ
    return (value * 10000) / 127;
}
```

#### 2.1.2 典型值
- 最小值（0）：0Ω
- 中间值（64）：约5kΩ
- 最大值（127）：10kΩ

### 2.2 ADC扩展器

#### 2.2.1 值转换
- 8位ADC值（0-255）映射到12位范围（0-4095）
- 电压计算：`voltage = (adc_value * 3.3) / 4095`

#### 2.2.2 通道状态检测
通过电压阈值判断通道状态：
- < 50mV：判定为接地或未连接
- > 50mV：判定为有效连接

## 3. 测试结果

### 3.1 数字电位器测试
```
TPL0401A set to minimum: 0 ohms
TPL0401A set to middle: 5039 ohms
TPL0401A set to maximum: 10000 ohms
```

### 3.2 ADC通道测试结果

| 通道 | 原始值(hex) | 12位值 | 电压(mV) | 状态 |

| 0    | 0x32      | 802    | 646      | 已连接 |
| 1    | 0x20      | 513    | 413      | 已连接 |

### 3.3 关键发现
1. 通道1和7显示完全相同的电压（413mV）
2. 通道5和6完全接地（0mV）
3. 通道3在阈值边缘（51mV）
4. ADC读数非常稳定，没有观察到波动

## 4. 优化建议

### 4.1 阈值调整
考虑实施双阈值系统：
- < 50mV：确认为接地
- < 100mV：判定为未连接
- > 100mV：确认为有效连接

### 4.2 采样策略
当前采用单次采样策略，因为：
1. 读数非常稳定
2. 未观察到明显的噪声
3. 响应速度快

## 5. 注意事项

1. ADC扩展器的高字节始终为0xFF，仅使用低字节
2. 建议在读取ADC值后等待一小段时间（如10ms）再进行下一次读取
3. TPL0401A的值写入后立即生效，无需等待
